# Model Card## Model name**RiceResilience-AI multi-stage proof-of-concept framework**## Model summaryThis model is a computational framework designed to simulate, analyze, and rank rice genotypes for resilience under **combined heat, drought, salinity, and oxidative stress** across two developmental stages: **seed-stage establishment** and **reproductive-stage performance**.It combines biologically structured synthetic data with statistical learning and machine-learning methods to identify predictive features of stress resilience and to generate breeder-oriented genotype rankings.## Model typeThis repository includes multiple model components rather than a single predictive model. The main predictive components are:- Random forest regression- Gradient boosting regression- Multilayer perceptron regressionThese are used for two supervised tasks:1. Predicting **seed-stage germination**2. Predicting **reproductive-stage yield per plant**## Intended use### Primary intended uses- Proof-of-concept modeling of rice stress resilience- Demonstration of AI-assisted breeding prioritization- Training and education in crop stress analytics- Workflow development for multi-stage trait integration- Hypothesis generation for empirical rice stress experiments### Appropriate users- Plant scientists- Crop physiologists- Computational biologists- Agricultural data scientists- Breeders interested in climate-smart selection frameworks- Students learning applied AI in agriculture## Out-of-scope usesThis model should **not** be used for:- Real-world breeding decisions without empirical validation- Estimating actual field performance of specific rice cultivars- Regulatory claims- Agronomic recommendations for farmers- Mechanistic inference about gene function from simulated expression values- Clinical, medical, or non-plant applications## Training and evaluation dataThe model was trained and evaluated using **synthetic, literature-guided data** generated within the notebook. The data were constructed to reflect biologically plausible responses reported in rice stress literature, including:- Reduced germination and root growth under salinity and combined stress- Increased Na?/K? imbalance under salinity-containing environments- Increased H?O? and MDA under oxidative and combined stress- Increased proline and antioxidant responses under stress- Reduced pollen viability and spikelet fertility under heat-containing stress- Reduced yield under combined stressThe model was not trained on measured field or greenhouse observations.## Input features### Seed-stage prediction inputs- Genotype identity- Subpopulation class- Stress treatment- Latent resilience features- Root length- Vigor index- Na?/K? ratio- H?O?- MDA- Proline- SOD- CAT- APX- Relative expression features### Reproductive-stage prediction inputs- Genotype identity- Subpopulation class- Stress treatment- Latent resilience features- Pollen viability- Spikelet fertility- Grain weight- Photosynthesis- Na?/K? ratio- H?O?- MDA- Proline- SOD- CAT- APX- Relative expression features## Output targets### Seed-stage task- Germination percentage### Reproductive-stage task- Yield per plant## Performance measuresThe workflow evaluates models using:- R?- RMSE- MAEBecause the data are simulated, these metrics indicate internal predictive consistency within the synthetic framework, not real-world agronomic accuracy.## InterpretabilityInterpretability is a major design feature of this framework.The model includes:- Treatment-level summaries- Correlation matrices- PCA plots- Feature-importance ranking using permutation importance- Resilience indices- Composite breeding-priority scoringThese outputs were included to make prediction biologically understandable rather than purely statistical.## Key findings from the proof of conceptThe framework recovered several biologically plausible patterns:- Combined stresses were more damaging than single stresses- Germination was strongly linked to oxidative and osmotic indicators- Yield was strongly linked to spikelet fertility and pollen viability- Oxidative and ionic stress markers were negatively associated with performance traits- Combined-tolerant genotypes outperformed susceptible ones across developmental stages## Limitations- Synthetic data only- No field validation- No real genotype marker data- No true omics measurements- No explicit soil, microbiome, or management effects- Expression variables are stylized relative signals, not empirical transcripts- Performance metrics do not translate directly to real breeding populations## Biases and risksThe model inherits several structural biases from its design assumptions:- It assumes that oxidative stress is a central convergence layer- It emphasizes fertility as the main driver of reproductive yield- It uses class-based latent resilience distributions- It treats combined stress as non-additive by design- It assumes certain variables are beneficial adaptive responsesThese choices are scientifically motivated, but they still bias what the model is likely to detect.## Ethical and scientific considerationsThis model is intended for plant science and crop research only. It should be used responsibly as a **conceptual and computational tool**, not as a substitute for empirical validation.Users should clearly state that:- the dataset is simulated,- the predictions are proof-of-concept,- and the framework is exploratory rather than decision-final.## MaintenanceThis model card should be updated if:- real empirical data are added,- new stress types are incorporated,- genomic features are introduced,- or the model is re-parameterized for a new crop or breeding target.## VersionVersion: 1.0  Status: Proof of concept
